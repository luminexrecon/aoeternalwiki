Quick reference

Panduan Giveaway Overlay

Cara singkat menyalakan & memakai overlay giveaway di OBS — dari nyalain server sampai tekan SPIN. Server jalan lokal di PC kamu sendiri, tidak butuh internet.

Sebelum live (sekali saja)

Cukup dilakukan sekali waktu pertama setup.

1

Install Node.js dari nodejs.org kalau belum ada. Cek dengan buka Command Prompt lalu ketik node --version.

2

Double-click start-server.bat di folder project sekali. Dependency ke-install otomatis, tunggu sampai muncul pesan server berjalan.

Setiap mau live

Urutan yang diulang tiap sesi live.

1

Double-click start-server.bat. Biarkan jendela terminalnya tetap terbuka (boleh minimize) selama live.

2

Pilih model di bawah, lalu tambahkan URL Overlay (dan Winner kalau mau) sebagai Browser Source baru di OBS.

Background transparan otomatis. Atur ukuran source minimal lebar 1000px.

3

Buka URL Control Panel di tab browser biasa (Chrome/Edge) — bebas dipindah ke monitor manapun. Bisa juga ditempel di OBS lewat Docks → Custom Browser Docks.

Pilih model

Dua model bisa dipakai bersamaan (scene berbeda) — datanya terpisah sepenuhnya.

Overlay http://localhost:3000/giveawayspinner/overlay
Winner http://localhost:3000/giveawayspinner/winner
Control http://localhost:3000/giveawayspinner/control
  1. Di Control Panel, isi form Tambah Item: nama, qty, format qty, bobot peluang (opsional), gambar (auto crop 540×540px).
  2. Butuh banyak item cepat? Pakai Import Cepat — satu baris Nama;Qty;Format.
  3. Tekan SPIN — strip gambar bergerak dari kanan ke kiri, melambat, berhenti di 1 pemenang (7 detik), lalu reveal tampil 5 detik.
Overlay http://localhost:3000/chat-spinner/overlay
Winner http://localhost:3000/chat-spinner/winner
Control http://localhost:3000/chat-spinner/control
  1. Tambah item seperti biasa (nama, qty, format, bobot, gambar).
  2. Di bagian Peserta, tambahkan nama-nama yang ikut diundi (satu-satu atau Import Cepat, satu nama per baris). Semua peserta peluangnya sama rata.
  3. Tekan SPIN — 1 item & 1 peserta terpilih bersamaan, gambar+nama item dan nama peserta berganti-ganti cepat lalu melambat dan mendarat bersamaan (7 detik), reveal tampil 5 detik.

Tips cepat

% Bobot cuma menentukan peluang menang (bobot 2× = 2× lebih sering menang) — tidak memengaruhi kecepatan spin atau seberapa sering item itu kelihatan pas lagi berputar.
↻ Aktifkan "Hapus setelah menang" di Pengaturan kalau stok hadiah terbatas, supaya item yang sudah menang tidak bisa menang lagi.
♪ Mau ada suara? Taruh spin.mp3 & win.mp3 di folder assets/sfx/ masing-masing model. Tanpa file itu, overlay tetap jalan normal (silent).

Kalau ada masalah

! Muncul "Tidak terhubung ke server" → pastikan jendela start-server.bat masih terbuka dan tidak error. Refresh Browser Source di OBS setelah server jalan lagi.
! Port 3000 bentrok aplikasi lain → jalankan lewat Command Prompt: set PORT=4000 && node server.js, lalu ganti semua URL di atas dari 3000 ke 4000.
Data (daftar item, peserta, riwayat) tersimpan lokal di folder data/, gambar di uploads/ — semuanya di komputer kamu sendiri, tidak terkirim ke internet.
